    Project Specification

    Project Title

    Free-Form Deformation (FFD) in Unity

    Aim

    The aim of this project is to implement and study a Free-Form Deformation system in Unity using a 3D control lattice and Bernstein polynomial-based weighting.

    Motivation

    FFD is a fundamental geometric deformation technique used in computer graphics, modeling, and animation.

    Objectives

    • Implement a 3×3×3 control lattice
    • Map mesh vertices into STU parametric space
    • Evaluate deformation using Bernstein polynomials
    • Allow real-time interaction with control points

    Methods

    • Free-Form Deformation (Sederberg & Parry)
    • Bernstein basis functions
    • Unity C# implementation

    Expected Outcome

    A real-time interactive mesh deformation system.

    Tools

    • Unity 6
    • C#
    • GitHub

    References

    • Sederberg & Parry (1986), FFD paper
